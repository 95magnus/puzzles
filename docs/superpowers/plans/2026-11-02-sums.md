# Sums Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Sums, a daily + practice page (`sums.html`): strike digits from a grid until every row and column adds up to its target, with 3 lives for striking a digit that belongs.

**Architecture:** Same shape as Tangle and Loop: pure, DOM-free `sums/{types,solver,generate,game}` modules, a DOM-grid renderer `sums/board`, and `sums/app` handing a `PuzzleGame` definition (with `attempts: true`) to the shared `ui/puzzleApp` shell. Puzzles draw random digits and a random keep mask, and are accepted only when the line-subset deduction solver (plus one-step trials) solves them completely. Tangle's lives display moves to `ui/hud` so both games share it.

**Tech Stack:** TypeScript, Vite (multi-page), Vitest (+ jsdom), Playwright. No UI framework.

**Spec:** `docs/superpowers/specs/2026-11-02-sums-design.md`

## Global Constraints

- Work on a new branch `feat/sums` cut from `main` (the spec is committed on `main`). Never `git push`.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Conventional commits scoped `sums` (`feat(sums): …`), `refactor(ui): …` for the lives move, `test(e2e): …`.
- No new dependencies.
- Indexing: cells `r * size + c`; lines `0..size-1` are rows, `size..2*size-1` are columns.
- `Cell` is `0` open, `1` struck, `2` marked, `3` locked. Marked counts as open for every rule.
- Presets: `easy` 5×5, `medium` 7×7 (default + daily), `hard` 9×9; labels Easy / Medium / Hard. `generatePuzzle` throws for sizes outside 5–9.
- Daily seed: `seedFromString('sums-daily:' + isoDate)`.
- Keep probability 0.55; every line keeps ≥ 1 and strikes ≥ 1 digit; at most 2000 attempts.
- `MAX_LIVES = 3`; mistake input pause 700 ms; red flash 500 ms; long-press 350 ms.
- Colours: remaining count amber `#ef9f27`; done target green `#5dcaa5`; locked ring violet `#7f77dd`; mistake flash red `#ff5c7a`.
- Cell size `clamp(30px, fit, 56px)` via `ui/fit` over `size + 1` tracks; 9×9 fits 375 px wide; no `bestOnComputer`.
- Copy: tagline "Strike out digits until every line adds up."; win title "All lines add up"; loss title "Out of lives"; dashboard `doneWord: 'Solved'`, `lostWord: 'Out of lives'`; flag `sums-howto-seen`.
- Animations off under `prefers-reduced-motion` (`reducedMotion()` from `ui/fit`).
- Run `npm test`, `npm run lint` and `npx tsc --noEmit` before each commit.

## Review Focus

1. **A long-press that is then released** — it marks the digit and must not also strike it (Task 5 test).
2. **A finger that slides from one cell to another before lifting** — nothing is struck; a strike needs down and up on the same cell (Task 5 test).
3. **Long-press on iOS/Android** — no text selection, callout or context menu appears (`user-select: none`, `-webkit-touch-callout: none`, `contextmenu` prevented) (Task 5 test).
4. **Two quick correct taps on different cells** — both strike; only a mistake pauses input (Task 5 test).
5. **A daily save written by an older generator** (the board for that date changed) — `restore` rejects it and the daily starts fresh instead of crashing (Task 3 test, Task 6 app test).

**Interfaces:**
- Produces:
  - `types.ts`: `Puzzle = { size: number; digits: number[]; targets: number[]; solution: (0 | 1)[] }`; `Cell = 0 | 1 | 2 | 3`; `Status = 'playing' | 'won' | 'lost'`; `GameState = { puzzle: Puzzle; cells: Cell[]; lives: number; status: Status; left: number }`; `PresetId = 'easy' | 'medium' | 'hard'`.
  - `solver.ts`: `lineRule(digits: number[], known: (0 | 1 | 2)[], target: number): { keep: boolean[]; strike: boolean[] } | null` — one line in isolation (`known` uses the `analyse` encoding; `keep[i]` / `strike[i]` true when every valid assignment agrees; `null` when none is valid); `lineCells(size: number): number[][]` (cached per size; `2 * size` lines, rows first, cells in order); `analyse(size: number, digits: number[], targets: number[]): Int8Array | null` — fixpoint state per cell (`0` unknown, `1` keep, `2` strike), `null` on contradiction; `deduce(size, digits, targets): (0 | 1)[] | null` — `analyse` with no unknowns left, keep → `1`, strike → `0`, else `null`; `countSolutions(size, digits, targets, limit: number): number`.
  - `helpers.ts`: `puzzle(size: number, digits: number[], keep: (0 | 1)[]): Puzzle` — computes `targets` from the keep mask.

**Algorithm** (spec §5).
- *Line rule*: for a line, enumerate bitmasks over its unknown cells; a mask is valid when kept-known sum + masked digits === target. AND / OR the valid masks to find cells kept in all / struck in all. No valid mask → contradiction. Worklist of lines; setting a cell enqueues its row and column.
- *Trials*: when the worklist drains with unknowns, for each unknown cell in index order: copy the state, set keep, propagate; contradiction → set strike in the real state, propagate, restart the plain rule. Else the same with strike → keep. Stop when a full sweep changes nothing. Trials never nest.
- *`countSolutions`*: backtracking over cells in index order; prune a line when its kept sum exceeds the target or its kept sum plus all its undecided digits falls short; check every line at the leaf; stop at `limit`.

  - `lineRule([2, 3, 1], [0, 0, 0], 6)` → keeps all three (the line sums to its target).
  - `lineRule([4, 2, 1, 3, 9], [0, 0, 0, 0, 0], 7)` → keeps only index 0 (in both `{4,2,1}` and `{4,3}`), strikes only index 4.
