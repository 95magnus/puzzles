# Patches Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Patches, a daily + practice rectangle-partition puzzle page (`patches.html`): cover the grid with rectangles, each holding exactly one clue and matching its shape and area.

**Architecture:** Same shape as Queens: pure, DOM-free `patches/{types,rect,solver,generate,game,input}` modules, a DOM-grid renderer `patches/board` with rectangle tiles layered over the cells, and `patches/app` wiring routes, HUD, win card and storage. Puzzles are generated deterministically (random partition → one full clue per rectangle → uniqueness repair → hide areas/shapes while still unique → greedy colouring). The dashboard gains a registry entry.

**Tech Stack:** TypeScript, Vite (multi-page), Vitest (+ jsdom), Playwright. No UI framework.

**Spec:** `docs/superpowers/specs/2026-10-23-patches-design.md`

## Global Constraints

- Branch `feat/patches` cut from `main` (the spec is already on `main`); commit this plan as its first commit if it is not on `main` yet. Never `git push`.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- No new dependencies.
- Cells are flat indices `r * size + c`. `Rect = { r, c, w, h }` — `w` columns, `h` rows. Shapes: `square` w = h (1×1 is square), `wide` w > h, `tall` h > w, `any`.
- Presets: `small` 6×6, `medium` 8×8 (default + daily), `large` 10×10. Sizes outside 4–10 throw.
- Daily seed: `seedFromString('patches-daily:' + isoDate)`.
- No lives, no attempts. Win = every cell covered and no invalid rectangle.
- A clue never has both a hidden area and shape `any`.
- Tile fill: clue colour at ~35 % over the board background, 2 px border in full colour; rectangles without exactly one clue are neutral grey; invalid colour `#ff5c7a`.
- Cell size `clamp(30px, fit, 56px)`; 10×10 fits 375 px wide; the page never scrolls horizontally.
- All `localStorage` access in try/catch; the game works without storage.
- Copy: tagline "Cut the grid into patches. One clue each."; win title "Patched up"; dashboard done word "Solved".
- Animations off under `prefers-reduced-motion`.
- Run `npm test` and `npx tsc --noEmit` before each commit.

## Review Focus

1. A tap on a cell covered by a rectangle removes that rectangle; it must never also place a 1×1 there. A tap on an uncovered cell places a 1×1. (Task 4 test `tap removes a covering rectangle, else places 1×1`.)
2. A draw that replaces several rectangles undoes in one step and brings back exactly the replaced ones. (Task 4 test `undo after a replacing draw restores every replaced rectangle`.)
3. A rectangle on a shape-only clue is valid at any area of that shape, and an `any` clue accepts all three shapes at its area — the game's validity must agree with the solver's candidates. (Task 4 test `validity agrees with solver candidates`.)
4. A daily save with overlapping or out-of-bounds rectangles must start a fresh board, not crash; a tab must not overwrite a solved save from another tab. (Task 4 `restore rejects bad input`; Task 8 `persist never overwrites a solved save from another tab`.)
5. Hand-edited hash `#/practice?preset=bogus&seed=abc` → Medium, random seed, no crash. (Task 8 test in `parsePatchesRoute`.)

### Task 2: Solver

**Files:**
- Create: `src/patches/solver.ts`
- Modify: `tests/patches/helpers.ts` (fill `solution` via `solve`)
- Test: `tests/patches/solver.test.ts`

**Interfaces:**
- Consumes: Task 1.
- Produces:
  - `candidates(p: Puzzle, i: number): Rect[]` — every in-bounds rectangle containing `clues[i].cell`, containing no other clue cell, with `fits(shape)` and `w*h === area` when `area` is defined.
  - `countSolutions(p: Puzzle, limit: number): number` — ignores `p.solution`; stops at `limit`.
  - `solve(p: Puzzle): Rect[] | null` — first solution, aligned with `clues`.
  - `isSolution(p: Puzzle, rects: Rect[]): boolean` — rules of spec §2 checked directly (used by tests and the generator self-check).

**Search** (spec §5): precompute each candidate's cell set as a bitset of `Math.ceil(size² / 32)` `Uint32` words. At each node: among unplaced clues, count candidates that don't intersect the covered bitset; pick the clue with the fewest (return on zero); before branching, check the lowest uncovered cell is in some compatible candidate of an unplaced clue (else return). Try each compatible candidate, recurse. A full placement covering every cell counts one solution. (A placement where all clues are placed but cells remain uncovered is not a solution.)

  - `impossible board counts 0`: `NONE4` → `0`; `solve` → `null`; `candidates(p, 0)` is empty.
  - `hidden area widens candidates`: `UNIQUE4` with clue 3 as `[3, 'tall']` → `candidates(p, 1).length === 3`, count still `1`.
  - `any accepts every shape at its area`: `UNIQUE4` with clue 3 as `[3, 'any', 4]` → `candidates(p, 1).length === 1`, count `1`.
  - `isSolution` true for the fixture solution; false with one rectangle shrunk (cells uncovered) and false with two swapped.

### Task 3: Generator

**Files:**
- Create: `src/patches/generate.ts`
- Test: `tests/patches/generate.test.ts`

**Interfaces:**
- Consumes: Tasks 1–2; `mulberry32`, `seedFromString`, `randInt`, `shuffle` from `src/core/rng.ts`; `PALETTE` length (9) from `src/ui/palette.ts`.
- Produces:
  - `PRESETS: Record<PresetId, { size: number; label: string; maxArea: number; hideArea: number; anyShape: number }>` — `small` `{6, 'Small', 6, 0.2, 0.1}`, `medium` `{8, 'Medium', 8, 0.3, 0.15}`, `large` `{10, 'Large', 10, 0.35, 0.15}`.
  - `DAILY_PRESET: PresetId = 'medium'`
  - `patchesDailySeed(isoDate: string): number`
  - `generatePuzzle(size: number, seed: number): Puzzle` — deterministic per `(size, seed)`; one `mulberry32(seed)` drives everything. Preset parameters are looked up by size; sizes 4, 5, 7, 9 (no preset) use `maxArea = size`, `hideArea 0.3`, `anyShape 0.15`.
  - `adjacent(a: Rect, b: Rect): boolean` — share an edge segment of length ≥ 1; exported for tests.

**Algorithm** (spec §4):
```
generatePuzzle(size, seed):
  throw if size < 4 or size > 10
  rng = mulberry32(seed); cfg = params(size)
  repeat up to 2000 times:
    rects = partition(size, cfg.maxArea, rng)
      // first uncovered cell in reading order = top-left; list every w×h anchored there that fits
      // uncovered cells with area ≤ maxArea; weight: area 1 → 1, area 2 → 2, area 3–6 → 4, area ≥ 7 → 2,
      // and halve the weight of 1×N / N×1 strips with N ≥ 4; pick by weight
    if count(1×1 rects) > ceil(0.1 * rects.length): continue
    clues[i] = { cell: random cell of rects[i], shape: shapeOf(rects[i]), area: w*h, color: 0 }
    sort clues by cell (carry rects along)
    repeat up to 30 repair steps while (alt = second solution) exists:   // countSolutions(p, 2) == 2
      i = first clue whose rect in alt differs from rects[i]
      move clues[i].cell to a random untried cell of rects[i]; if all tried, merge rects[i] with an
      adjacent rect j when their union is a rectangle with area ≤ maxArea (keep one clue at a random cell
      of the union, drop the other); if no merge is possible, abandon the attempt
      re-sort clues by cell
    if not unique: continue
    hide(clues, 'area', round(cfg.hideArea * n)): visit clues in shuffled order, delete area,
      keep iff countSolutions == 1, stop at the target
    hide(clues, 'shape', round(cfg.anyShape * n)): same over clues that still show an area, setting shape = 'any'
    colour: smallest-last order over the solution adjacency graph, each clue gets the lowest index not used by
      already-coloured neighbours (planar ⇒ ≤ 6 colours), then add offset = randInt(rng, 9) mod 9
    return { size, clues, solution: rects }
  throw new Error('patches: no unique puzzle')
```

**Interfaces:**
- Consumes: Tasks 1–2; `pz`, `UNIQUE4` from helpers.
- Produces (mutating actions return `true` iff something changed; all return `false` once `s.status === 'won'`, and each change re-checks the win):
  - `newGame(p: Puzzle): GameState`
  - `checkRect(p: Puzzle, x: Rect): { clue: number | null; ok: boolean }` — `clue` = index of the single clue inside `x` (else `null`); `ok` iff exactly one clue, `fits(shape)` and area matches when shown.

  - `removeAt(s: GameState, cell: number): boolean`
  - `tap(s: GameState, cell: number): boolean` — `removeAt` if a rect covers `cell`, else `place` a 1×1.
  - `undo(s: GameState): boolean`, `clear(s: GameState): boolean` — clear is one move; no move when empty.
  - `invalid(s: GameState): Set<number>` — indices into `s.rects` where `!checkRect(...).ok`.
  - `coverage(s: GameState): number`, `isWin(s: GameState): boolean`
  - `encode(s: GameState): string` — rects sorted by `(r, c)`, `"r,c,w,h"` joined by `;` (`''` when empty).
  - `restore(p: Puzzle, text: string): GameState | null` — `null` on bad format, out of bounds, or overlap; empty history; status from `isWin`.

**Interfaces:**

  export type InputEvent =
    | { type: 'down'; cell: number }
    | { type: 'move'; cell: number | null }   // null = off the board
    | { type: 'up' }
    | { type: 'cancel' };

    | { kind: 'tap'; cell: number }
