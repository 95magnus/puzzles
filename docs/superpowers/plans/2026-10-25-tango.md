# Tango Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Tango, a daily + practice sun/moon binary puzzle page (`tango.html`): fill the grid so every row and column is balanced, no three of a kind touch in a line, and every `=` / `×` clue holds.

**Architecture:** Same shape as Queens and Patches: pure, DOM-free `tango/{types,lines,solver,generate,game}` modules, a DOM-grid renderer `tango/board` with edge badges layered over cell borders, and `tango/app` wiring routes, HUD, win card and storage. Puzzles are generated deterministically (random solved grid → every cell given plus random edge clues → greedy clue removal while the line-wise deduction solver still finishes). The dashboard gains a registry entry.

**Tech Stack:** TypeScript, Vite (multi-page), Vitest (+ jsdom), Playwright. No UI framework.

**Spec:** `docs/superpowers/specs/2026-10-25-tango-design.md`

## Global Constraints

- Branch `feat/tango` (already exists; the spec is its first commit). Commit this plan on it. Never `git push`.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- No new dependencies.
- Cells are flat indices `r * size + c`. `Sym`: `0` empty, `1` ☀ sun, `2` ☾ moon. Line ids `0..size-1` are rows, `size..2·size-1` columns.
- Presets: `small` 6×6, `medium` 8×8 (default + daily), `large` 10×10. Edge-clue density 0.35; min givens = `size`. Sizes odd or outside 4–10 throw.
- Daily seed: `seedFromString('tango-daily:' + isoDate)`.
- No lives, no attempts. Win = every cell filled and no violation. The board is never compared with the solution during play.
- Rule-break red is `#ff5c7a`.
- Cell size `clamp(30px, fit, 56px)`; 10×10 fits 375 px wide; the page never scrolls horizontally.
- All `localStorage` access in try/catch; the game works without storage.
- Copy: tagline "Fill the grid with suns and moons."; win title "Balanced ☀☾"; dashboard done word "Solved".
- Animations off under `prefers-reduced-motion`.
- `tango.html` copies `patches.html` verbatim apart from title and entry (favicon and analytics script included).
- Run `npm test` and `npx tsc --noEmit` before each commit.

## Review Focus

1. Tapping a given changes nothing and pushes no history entry, so Undo never "undoes" a no-op. (Task 4 test `givens are locked and push nothing`.)
2. Violations must not fire on incomplete information: an edge with one empty cell, and a partly filled line holding exactly `size/2` of one symbol, are not flagged. (Task 4 test `no false alarms on partial lines and half-empty edges`.)
3. Undo after a violation clears the red styling; undo is ignored after a win. (Task 4 `undo recomputes violations`; Task 6 `render clears violation classes after undo`.)
4. A daily save whose cells disagree with today's givens (or has the wrong length) starts a fresh board instead of crashing; a tab never overwrites a solved save from another tab. (Task 4 `restore rejects changed givens`; Task 7 `daily ignores a save that contradicts the givens`, `persist never overwrites a solved save from another tab`.)
5. Hand-edited hash `#/practice?preset=bogus&seed=abc` → Medium, random seed, no crash. (Task 7 test in `parseTangoRoute`.)

### Task 2: Deduction solver

**Files:**
- Create: `src/tango/solver.ts`
- Modify: `tests/tango/helpers.ts` (fill `solution` via `deduce`)
- Test: `tests/tango/solver.test.ts`

**Interfaces:**
- Consumes: Task 1.
- Produces:
  - `propagate(p: Pick<Puzzle, 'size' | 'givens' | 'edges'>): Sym[] | null` — line-wise fixpoint from the givens (spec §5); `null` on contradiction; may leave zeros.
  - `deduce(p: Pick<Puzzle, 'size' | 'givens' | 'edges'>): Sym[] | null` — `propagate`, then `null` if any cell is still `0`.
  - `countSolutions(p: Pick<Puzzle, 'size' | 'givens' | 'edges'>, limit: number): number` — backtracking over cells in reading order; after each placement prune when either line through the cell has no surviving pattern. Tests only.
  - `isSolved(p: Pick<Puzzle, 'size' | 'edges'>, cells: Sym[]): boolean` — every cell filled, every line a member of `linePatterns(size)`, every edge holds. Used by tests and the generator self-check.

**Propagate** (one pass = all `2·size` lines; repeat until a pass sets nothing):
```
for each line i:
  cells = lineCells(size, i); es = lineEdges(p, i)
  alive = linePatterns(size).filter(pt =>
            cells.every((c, k) => g[c] === 0 || g[c] === pt[k]) &&
            es.every(e => (pt[e.x] === pt[e.y]) === e.eq))
  if alive is empty: return null
  for k with g[cells[k]] === 0: if all alive agree at k → set g[cells[k]] = alive[0][k], mark changed
```

- [ ] **Step 1: Write the failing tests**:
  - `deduces a deducible board`: `deduce(DEDUCE4)` equals `sym(DEDUCE4_SOLUTION)`; `countSolutions(DEDUCE4, 2) === 1`.
  - `stalls on an open board`: `deduce(EMPTY4) === null`; `propagate(EMPTY4)` is all zeros; `countSolutions(EMPTY4, 2) === 2` and `countSolutions(EMPTY4, 1) === 1`.
  - `contradiction returns null`: `propagate(CONTRA4) === null`, `deduce` null, `countSolutions(CONTRA4, 2) === 0`.
  - `edge chain fills a line`: `propagate(CHAIN6)` row 0 equals `sym('SMMSSM')`, cells 6..35 all `0`.
  - `isSolved`: true for `DEDUCE4_SOLUTION`; false with two cells swapped across a line (breaks balance or a triple), false with cell 1 and 5 equal (breaks the `×` edge), false with one cell emptied.

### Task 3: Generator

**Files:**
- Create: `src/tango/generate.ts`
- Test: `tests/tango/generate.test.ts`

**Interfaces:**
- Consumes: Tasks 1–2; `mulberry32`, `seedFromString`, `randInt`, `shuffle` from `src/core/rng.ts`.
- Produces:
  - `PRESETS: Record<PresetId, { size: number; label: string; edgeDensity: number; minGivens: number }>` — `small` `{6, 'Small', 0.35, 6}`, `medium` `{8, 'Medium', 0.35, 8}`, `large` `{10, 'Large', 0.35, 10}`.
  - `DAILY_PRESET: PresetId = 'medium'`
  - `tangoDailySeed(isoDate: string): number`
  - `generatePuzzle(size: number, seed: number): Puzzle` — deterministic per `(size, seed)`; one `mulberry32(seed)` drives everything. Size 4 (no preset) uses density 0.35, min givens 4.

**Algorithm** (spec §4):
```
generatePuzzle(size, seed):
  throw if size is odd, < 4 or > 10
  rng = mulberry32(seed); cfg = params(size)
  repeat up to 200 times:
    solution = fillSolution(size, rng)     // row-major backtracking, ☀/☾ order random per cell; reject a value that
                                           // makes three in a row ending here (left or up) or puts > size/2 of it in
                                           // its row or column; after 10 000 backtracks restart the fill
    edges = every internal edge (a, a+1 within a row; a, a+size within a column) kept with prob edgeDensity,
            kind 'eq' iff solution[a] === solution[b]
    givens = solution.slice()
    order = shuffle(rng, [...cells as {given: c}, ...edges as {edge: e}])
    for item in order:
      if given and count(givens ≠ 0) === minGivens: continue
      remove item tentatively; if deduce({size, givens, edges}) === null: put it back
    if edges.length >= 2: return { size, givens, edges (sorted by a, b), solution }
  throw new Error('tango: no puzzle')
```

  - `solution follows the rules`: `isSolved(p, p.solution)`; every non-zero given equals the solution; every edge's kind matches the solution — all presets, seeds 1..50.
  - `deducible and unique`: `deduce(p)` deep-equals `p.solution` and `countSolutions(p, 2) === 1` — all presets, seeds 1..50.

  - `throws on unsupported sizes`: 3, 7 and 12.
