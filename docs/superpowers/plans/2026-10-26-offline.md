# Offline Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the dashboard and every puzzle load and play offline after one online visit, with new deploys arriving on the next launch.

**Architecture:** A hand-written, self-contained service worker (`src/sw/`) precaches the whole build and serves it cache-first. A build-only Vite plugin (`build/offline.ts`) emits it as `sw.js`, injects the build's file list and a content-hash version, and adds a one-line registration script to every page.

**Tech Stack:** TypeScript, Vite 8 (rolldown), Vitest, Playwright. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-26-offline-design.md`

## Global Constraints

- Create branch `feat/offline` from `main` before Task 1 (the spec and this plan are already on `main`). Never `git push`.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Conventional commits: `feat(offline): ...`, `test(e2e): ...`, `docs: ...`.
- No new runtime or dev dependencies.
- Cache name `puzzles-<version>`; version is the first 12 hex chars of a SHA-256. Old caches are those starting with `puzzles-`.
- Service worker file is `sw.js` at the site root, never hashed. Registration: `navigator.serviceWorker.register('./sw.js')`, errors ignored.
- Precache = every bundle file plus every `public/` file, minus `sw.js` and `og.png`.
- `src/sw/` imports nothing outside `src/sw/`.
- The plugin runs only for `vite build` (`apply: 'build'`); `npm run dev` and Vitest never see a service worker.
- localStorage keys and saves are untouched.

## Review Focus

1. **Flow's generator worker missing from the cache.** `src/games/flow/client.ts` silently falls back to main-thread generation, so a board still renders offline and hides the gap. Task 4 asserts the cache holds a `generate.worker` file and the Inter `.woff2` files.
2. **Launch URLs with a query or hash** (`/?source=pwa`, `flow.html#/practice`) must load offline. Covered by `cacheKey` unit tests (Task 1) and an e2e step (Task 4).
3. **Blocked or failing registration** (private mode, policy) must not break pages. The existing e2e suite runs with `serviceWorkers: 'block'` (Task 4), so every existing spec exercises this path.
4. **A shared chunk leaking into `sw.js`, or placeholders left unreplaced**, would ship a worker that can't install. Task 3 makes the build fail on both and verifies the built file.
5. **Same-origin files outside the precache** (`og.png`, unknown paths) go to the network and are never cached. `cacheKey` returns `null` for them (Task 1), and Task 4 asserts `og.png` and `sw.js` aren't in the cache.

### Task 1: URL → cache key mapping

**Files:**
- Create: `src/sw/routes.ts`
- Test: `tests/sw/routes.test.ts`

**Interfaces:**
- Produces: `cacheKey(url: URL, scope: URL, precache: readonly string[]): string | null`. Returns the precache path (relative, e.g. `flow.html`, `assets/x.js`) or `null`.

- [ ] **Step 1: Write the failing tests**

`const scope = new URL('https://puzzles.solhaug.dev/'); const precache = ['index.html', 'flow.html', 'assets/flow-abc.js'];` and a helper `key(path, s = scope, p = precache) => cacheKey(new URL(path, s), s, p)`.

- `maps the root to index.html`: `key('/')` → `'index.html'`
- `keeps explicit html paths`: `key('/index.html')` → `'index.html'`; `key('/flow.html')` → `'flow.html'`
- `adds .html to extensionless paths`: `key('/flow')` → `'flow.html'`
- `ignores query and hash`: `key('/flow.html?x=1#/practice')` → `'flow.html'`; `key('/?source=pwa')` → `'index.html'`
- `returns hashed assets as-is`: `key('/assets/flow-abc.js')` → `'assets/flow-abc.js'`
- `returns null outside the precache`: `key('/og.png')`, `key('/nope.html')`, `key('/flow/')` → `null`
- `returns null for other origins`: `cacheKey(new URL('https://cloud.umami.is/script.js'), scope, precache)` → `null`
- `handles a sub-path scope`: with `s = new URL('https://x.github.io/puzzles/')`: `key('/puzzles/', s)` → `'index.html'`, `key('/puzzles/flow', s)` → `'flow.html'`, `key('/flow.html', s)` → `null`

- [ ] **Step 2: Run to verify they fail**

Run: `npx vitest run tests/sw/routes.test.ts`
Expected: FAIL, cannot resolve `src/sw/routes`

- [ ] **Step 3: Implement `cacheKey` in `src/sw/routes.ts`**

Different origin or path not under `scope.pathname` → `null`. Take the path after `scope.pathname`; empty or ending in `/` → append `index.html`; last segment without a `.` → append `.html`. Return it if `precache.includes` it, else `null`. No imports.

- [ ] **Step 4: Run to verify they pass**

Run: `npx vitest run tests/sw/routes.test.ts`
Expected: all PASS

### Task 2: Precache manifest

**Files:**
- Create: `build/offline.ts`
- Modify: `tsconfig.json` (`include` gains `"build"`)
- Test: `tests/build/offline.test.ts`

**Interfaces:**
- Produces: `export type BuildFile = { name: string; content: string | Uint8Array }` and `export function precacheManifest(files: BuildFile[]): { paths: string[]; version: string }`. Task 3 adds `offline()` to the same file.

- [ ] **Step 1: Write the failing tests**

- `sorts paths and drops sw.js and og.png`: input names `['flow.html', 'sw.js', 'assets/a.js', 'og.png', 'index.html']` → `paths` equals `['assets/a.js', 'flow.html', 'index.html']`
- `version is 12 hex chars`: matches `/^[0-9a-f]{12}$/`
- `version ignores input order`: same files reversed → same `version`
- `version changes when one file changes`: change one file's `content` → different `version`
- `version changes when a file is renamed`: same content, different name → different `version`
- `accepts binary content`: an entry with `Uint8Array` content (e.g. a font) is included in `paths`, and changing one of its bytes changes `version`
- `ignores excluded files in the version`: changing `og.png`'s content leaves `version` unchanged

- [ ] **Step 2: Run to verify they fail**

Run: `npx vitest run tests/build/offline.test.ts`
Expected: FAIL, cannot resolve `build/offline`

- [ ] **Step 3: Implement `precacheManifest` in `build/offline.ts`**

Filter out `sw.js` and `og.png`, sort by `name`, hash with `node:crypto` `createHash('sha256')`, updating with each `name`, a `'\0'` separator, then `content`; `version` = `digest('hex').slice(0, 12)`. Add `"build"` to `tsconfig.json` `include`.

- [ ] **Step 4: Run tests and type-check**

Run: `npx vitest run tests/build/offline.test.ts && npx tsc --noEmit`
Expected: all PASS, no type errors

- [ ] **Step 5: Commit**

```bash
git add build/offline.ts tests/build/offline.test.ts tsconfig.json
git commit -m "feat(offline): list and version the files to precache"
```

### Task 3: Service worker and Vite plugin

**Files:**
- Create: `src/sw/sw.ts`
- Modify: `build/offline.ts` (add `offline()`), `vite.config.ts` (add `plugins: [offline()]`)

**Interfaces:**
- Consumes: `cacheKey` (Task 1), `precacheManifest` (Task 2).
- Produces: `export function offline(): Plugin` (from `vite`). The built site has `dist/sw.js` and every page registers it.

- [ ] **Step 1: Write `src/sw/sw.ts`**

`declare const __PRECACHE__: string[]; declare const __VERSION__: string;` and `const sw = self as unknown as ServiceWorkerGlobalScope;` (the project's DOM+WebWorker libs make redeclaring `self` a conflict; same cast style as `generate.worker.ts`). `CACHE = 'puzzles-' + __VERSION__`. Resolve paths with `new URL(path, sw.registration.scope)`.
- `install`: `waitUntil` opening `CACHE` and `cache.addAll(__PRECACHE__.map(p => new Request(new URL(p, scope), { cache: 'reload' })))`, then `sw.skipWaiting()`.
- `activate`: `waitUntil` deleting every `caches.keys()` entry that starts with `puzzles-` and isn't `CACHE`. No `clients.claim()`.
- `fetch`: return without `respondWith` unless `request.method === 'GET'` and `cacheKey(new URL(request.url), new URL(scope), __PRECACHE__)` is non-null; otherwise `respondWith` the `caches.open(CACHE)` match for that key's URL, falling back to `fetch(request)`.

Imports only `./routes`.

- [ ] **Step 2: Add `offline(): Plugin` to `build/offline.ts`**

`name: 'puzzles-offline'`, `apply: 'build'`, `enforce: 'post'`.
- `configResolved(config)`: keep `config.publicDir`.
- `buildStart`: `this.emitFile({ type: 'chunk', id: resolve('src/sw/sw.ts'), fileName: 'sw.js' })`.
- `generateBundle(_, bundle)`: find the `sw.js` chunk; if `chunk.imports.length || chunk.dynamicImports.length` → `this.error('sw.js must not import shared chunks; keep src/sw/ self-contained')`. Build `BuildFile[]` from every bundle entry (`code` for chunks, `source` for assets) plus every file under `publicDir` (`readdirSync(publicDir, { recursive: true })`, files only, names with `/` separators), call `precacheManifest`. Replace `__PRECACHE__` with `JSON.stringify(paths)` and `__VERSION__` with `JSON.stringify(version)` in `chunk.code`; if either placeholder isn't found → `this.error`.
- `transformIndexHtml()`: return `[{ tag: 'script', injectTo: 'head', children: "if ('serviceWorker' in navigator) navigator.serviceWorker.register('./sw.js').catch(() => {});" }]`.

Add `plugins: [offline()]` to `vite.config.ts`, importing `./build/offline.ts`.
